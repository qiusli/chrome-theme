# Deep Green Ocean Chrome Theme

A dark teal Chrome theme based on the supplied underwater photograph. Back,
Forward, Reload, Home, and other toolbar icons use a lighter seafoam green for
clear contrast.

## Install locally

1. Open `chrome://extensions` in Chrome.
2. Turn on **Developer mode**.
3. Click **Load unpacked**.
4. Select this `Chrome Theme` folder.

To remove it, open Chrome Settings, choose **Appearance**, then select
**Reset to default** beside Theme.

## Palette

- Tab bar: `#020F0E`
- Inactive tabs: `#020F0E`
- Active tab and toolbar: `#061D1B`
- Toolbar icons: `#7EBE9A`
- Omnibox: `#051F1D` with `#7EBE9A` URL text
- New-tab background: `#051D1D`
